## Несколько пасек — локальная проверка

В `client` запустите `npm run preview:apiaries` и откройте `http://127.0.0.1:5174`.
По умолчанию выбор пасеки скрыт: иконка рядом с названием раскрывает и сворачивает управление.

Это изолированный режим с тестовыми пасеками и ульями: записи хранятся только
в localStorage браузера, запросы к рабочим Supabase и Render заменены локальными
обработчиками. Погода запрашивается для выбранной точки у Open-Meteo. Можно создать
пасеку, переименовать её, выбрать локацию, добавить и перенести улей. При переносе
сохраняются номер и история; номер улья остаётся уникальным в рамках аккаунта.
Кнопка «Сбросить тестовые данные» возвращает исходные тестовые пасеки.
Код этого режима исключается из production-сборки.

Миграция `20261125193128_multiple_apiaries.sql` подготовлена и проверена локально
на изолированном PostgreSQL (PGlite). Миграция применена к рабочему проекту Supabase 25.11.2026.
При публикации сначала применяется миграция, затем обновляется сервер, затем
клиент. Существующие ульи и пользовательская локация попадают в «Основную пасеку».
Число новых пасек приложением не ограничено; списки читаются постранично, чтобы
ограничение одного ответа Supabase не обрезало список.
